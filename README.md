# EDA on Multiple Datasets

This repository contains exploratory data analysis work and a spam classification notebook created as part of lab work for the AI subject studied in BIM 5th semester.

## Contents

- `Datasets/`
  - `Automobile.csv`
  - `EnglishSpam.csv`
  - `HousePricePrediction.csv`
  - `StudentsPerformance.csv`
- `notebooks/`
  - `EDA on automobile dataset.ipynb`
  - `EDA on HousePricePrediction Dataset.ipynb`
  - `EDA on StudentsPerformance Dataset.ipynb`
  - `Spam_classification_with_Naive_Bayes_(test_size_30_).ipynb`

## Project Summary

The notebooks in this repository cover:

- data loading and inspection
- cleaning and preprocessing
- summary statistics and visualization
- correlation analysis and outlier detection
- spam classification using Naive Bayes

## How to Use

Open the notebooks in Jupyter Notebook, JupyterLab, or VS Code and run the cells in order. The datasets are stored in the `Datasets/` folder and are referenced using local file paths inside the notebooks.
